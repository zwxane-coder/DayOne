# DayOne Project

DayOne is a web application that explores historical events, music, technology, and milestones based on specific dates.

## Directory Structure
- `index.html` - Homepage
- `css/` - Custom stylesheets for each section
- `js/` - JavaScript logic scripts
- `images/` - Image directories (hero, history, music, tech, etc.)
- `assets/` - Fonts and icons
